<h3 align="center">The first agentic Growth OS</h3>

<p align="center">An experiment tracker your AI agents read and write through MCP.</p>

Hypotize keeps the record of every growth experiment: a scored backlog, a lifecycle that moves one stage at a time, and the outcome and learning of every test. Your agent reads what the team already tested before it proposes the next one. The server refuses to close an experiment without a measured result and a written learning.

**Connect an agent**

- MCP server: `https://api.hypotize.ai/mcp` (OAuth). Works with Claude, ChatGPT, Codex, Cursor and any MCP client.
- Claude Code: `/plugin marketplace add hypotizeai/hypotize-plugin`, then `/plugin install hypotize`
- Codex: `codex plugin marketplace add hypotizeai/hypotize-plugin`
